# 🛡️ Security Reports

Коллекция отчётов об уязвимостях, найденных в ходе практического тестирования на проникновение (пентеста) на учебных стендах и легальных платформах.

---

## 📋 О репозитории

Здесь я собираю структурированные отчёты по найденным уязвимостям. Каждый отчёт содержит:
- Описание уязвимости
- Тип и критичность (CVSS)
- Пошаговые инструкции по воспроизведению
- Доказательства (payload, скриншоты)
- Влияние на бизнес
- Рекомендации по устранению

Цель — показать навыки не только поиска, но и **профессионального оформления** результатов, что является ключевой частью работы пентестера.

## 🛠️ Использованные инструменты

- **Burp Suite Community** — перехват и модификация HTTP-запросов
- **DVWA (Damn Vulnerable Web Application)** — учебный стенд для практики
- **OWASP ZAP** — автоматизированное сканирование
- **Nmap** — сканирование портов и сервисов
- **Python** — написание собственных инструментов (сканер уязвимостей)

---

## 🧪 Методология

Каждый отчёт составлен по следующему шаблону:

1. **Заголовок** — название уязвимости и критичность
2. **Краткое описание** — для руководства (2-3 предложения)
3. **Тип уязвимости** — SQLi, XSS, CSRF и т.д.
4. **Критичность** — Low / Medium / High / Critical (CVSS)
5. **Затронутый компонент** — URL, параметр, эндпоинт
6. **Шаги воспроизведения** — пошагово, с примерами
7. **Доказательство** — скриншоты, вывод команд, payload
8. **Влияние (Impact)** — что может сделать злоумышленник
9. **Рекомендации по устранению** — как исправить
10. **Ссылки** — OWASP, CWE, CVE

---

## ⚠️ Важное предупреждение

**Все отчёты созданы исключительно в образовательных целях.**

Тестирование проводилось на:
- Собственных учебных стендах (DVWA в Docker)
- Легальных платформах, которые явно разрешают тестирование

**Запрещено:** использовать описанные техники на чужих системах без письменного разрешения владельца. Это уголовно наказуемо (ст. 272, 273 УК РФ).
